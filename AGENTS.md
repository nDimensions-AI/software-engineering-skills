# Engineering Skills Index
Before any coding task, read `skills/engineering-workflow/SKILL.md`, then load the skill(s) that match the task:

| Task | Skill |
|---|---|
| New app / MVP / system design + build | app-from-scratch |
| Unfamiliar codebase, audit, quality refactor | codebase-onboarding |
| Convert to clean/hexagonal architecture | clean-architecture |
| Large build with Architect/Engineer/Reviewer/Optimizer roles | multi-agent-workflow |
| Reusable UI component | ui-component-builder |
| Architecture decisions | architecture-design |
| Any new behavior or bug fix | tdd |
| Bugs, crashes, flaky tests | debugging |
| Reviewing code | code-review |
| Small structural cleanup | refactoring |
| HTTP/gRPC/library/CLI interfaces | api-design |
| Screens, flows, UX, accessibility | frontend-ui-ux |
| Speed, memory, scaling | performance |
| Input, auth, secrets, data | security |
| Commits and PRs | git-workflow |

Each lives at `skills/<name>/SKILL.md`.
