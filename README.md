# Engineering Skills (portable)
Agent Skills in the open `SKILL.md` format. Install:
- **Claude Code**: copy `skills/*` → `~/.claude/skills/` (global) or `<repo>/.claude/skills/`
- **GitHub Copilot**: copy `skills/*` → `<repo>/.github/skills/`
- **Codex**: copy `skills/*` → `~/.codex/skills/` or `<repo>/.agents/skills/`; copy `AGENTS.md` to repo root
- **Others (Cursor, Gemini CLI…)**: point the agent's rules file at `AGENTS.md`
